# 🍰 Rumah Siffon - Website Resmi 

Website profil dan katalog produk resmi untuk **Rumah Siffon**, UMKM kuliner spesialis cake lembut, siffon, proll tape khas Jember, dan aneka bakery berkualitas 
---

## ✨ Fitur Utama

- **Hero Slider Responsif**: Banner promo interaktif dan responsif di perangkat mobile maupun desktop dengan kontrol swipe dan pagination gold pill.
- **Katalog 26 Produk Resmi**:
  - 🍰 **Cake & Siffon**: Siffon Keju, Pandan, Strawberry, Siffon Coklat, Roll Cake, Spiku Kenari, Bolu Pandan, Abon Roll.
  - 🥧 **Proll Tape Khas Jember**: Prolltape Ori, Prolltape Mix, Prolltape Brownis.
  - 🍞 **Roti & Bakery**: Roti Abon, Roti Pizza, Chococrun, Roti Zebra, Coating Nut, Roti Sosis, Long Cheese, Pisang Coklat, Roti Blueberry, Roti Strawberry, Circle Coklat, Golden Cheese, Roti Sobek, Roti Sisir, Roti Kombinasi Coklat Keju.
  - 🧁 **Kue & Pastry**: Banana Cup Keju, Banana Cup Coklat.
- **Pencarian Langsung & Filter Kategori**: Cari produk berdasarkan nama dan filter cepat per kategori secara real-time.
- **Pemesanan Mudah via WhatsApp**: Integrasi tombol pesan langsung ke formulir WhatsApp dengan otomatis memilih produk yang diinginkan.
- **Formulir Pemesanan Interaktif**: Halaman kontak terintegrasi dengan generator pesan WhatsApp instan.
- **Desain Modern & Estetik**: Sentuhan warna hijau sage, krem hangat, dan aksen emas elegan khas kuliner premium.

---

## 🛠️ Teknologi yang Digunakan

- **HTML5 & Semantic Elements**
- **Tailwind CSS 3.4.19** (Custom configured & minified)
- **Vanilla JavaScript** (Interaktivitas, filter, dan live search)
- **Swiper.js** (Hero Carousel Slider)
- **Lucide Icons** (Icon set modern)
- **AOS (Animate On Scroll)** (Animasi transisi halus)

## 🚀 Panduan Menjalankan Proyek Secara Lokal

1. **Clone repository ini**:
   ```bash
   git clone https://github.com/surobyy/rumah-siffon.git
   cd rumah-siffon
   ```

2. **Install dependensi (untuk Tailwind CSS)**:
   ```bash
   npm install
   ```

3. **Kompilasi CSS**:
   - Mode Build (Minified):
     ```bash
     npm run build
     ```
   - Mode Watch (Pengembangan):
     ```bash
     npm run watch
     ```

4. **Jalankan Website**:
   Buka file `index.html` langsung di browser atau gunakan server lokal seperti Live Server / Laragon.
